
# Documentación funcional del sistema

## 1. Descripción general del sistema

Este documento describe el sistema basado exclusivamente en las historias de usuario registradas en el proyecto "Historias de Usuario - RA Manager Fase 2". El sistema está orientado a la gestión académica, priorizando la infraestructura, la seguridad, la experiencia de usuario, el seguimiento académico y la visualización de información relevante mediante dashboards. La información aquí consolidada se limita a lo explicitado en las historias de usuario, sin suposiciones adicionales.

## 2. Actores del sistema

A partir de las historias de usuario disponibles, los actores identificados son:

- **Usuario general**

  *Nota: Las historias no especifican actores concretos como "docente", "estudiante", "coordinador", etc. La definición de actores es ambigua y general.*
